# 🚀 MASTER PROMPT – SSC Online Examination Platform (Production Ready)

## Project Overview

Build a **production-grade Online Examination Platform** for SSC, Banking, Railway, UPSC, State PSC, and other competitive exams.

The platform should have **three portals**:

1. Student Portal
2. Admin Portal
3. Super Admin Portal

The UI must be modern, responsive, minimal, and fast.

Use a clean design similar to Testbook, Oliveboard, PracticeMock, and Adda247, but create an original UI.
